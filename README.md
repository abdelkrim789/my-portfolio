# For Safa

A late birthday cake: it forms out of light, its candles go out when she blows on her phone (or holds a button), and it bursts into her name, with a music-box melody and a gift tag that counts the time since 14:20 on November 2.

- `index.html`: the page and the gift-tag message (edit the text there)
- `src/main.js`: the cake, the candles, the breath detection, the sequence
- `src/style.css`: the look

```
npm install
npm run build     # static site in dist/, works from any path
```

Live at https://abdelkrim789.github.io/my-portfolio/safa/ (the built files sit in `public/safa/` on `main`).
